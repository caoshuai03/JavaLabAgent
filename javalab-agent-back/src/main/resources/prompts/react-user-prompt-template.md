决策流程（必须按步骤思考）：

步骤 1：列出所有子问题
- 分析用户问题，识别包含的全部子问题（问题 1、问题 2、问题 3...）
- 标记每个子问题的类型：
  - 需要工具（地理位置、实时信息、知识库查询等）
  - 通用知识（编程概念、理论说明等）

步骤 2：检查已有观察
- 对于每个需要工具的子问题，检查「已有观察」中是否已有对应结果
- 列出尚未解决的子问题

步骤 3：决定下一步动作
- 如果存在任何需要工具的子问题且无观察结果 → 选择最优先的一个，输出 `{"action":"tool",...}`
- 如果所有需要工具的子问题都有观察结果 → 输出 `{"action":"final"}`，准备进入回答阶段
- 如果用户问题很简单（闲聊、打招呼）→ 直接输出 `{"action":"final"}`

步骤 4：确保格式正确
- 只输出一个 JSON 对象（不是数组）
- 如果输出 tool action：填写 toolName 和 toolInput
- 如果输出 final action：**只需要 `{"action":"final"}`，不要填写任何其他字段**

关键提醒：
- ⚠️ 严格只输出一个 JSON 对象，绝对不允许输出数组 `[{...}, {...}]`
- ⚠️ 调用工具时，finalAnswer 字段必须留空或不存在
- ⚠️ 输出 final 时，不要填写 finalAnswer，最终回答会由专门的回答模块生成
- ⚠️ 技能参考仅用于辅助判断，不要将技能文档内容复述到输出中
- ⚠️ 每轮只选择一个动作，不要试图一次解决多个子问题
